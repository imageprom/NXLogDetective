# Правила для сессий Claude в этом репозитории

## Порядок работы
- Работай в отдельной ветке от свежего `origin/main`. В `main` ничего не вливай. Никакого `--force` и `--force-with-lease`.
- Перед каждым коммитом: `git checkout -- data/reference/learned` (прогоны дописывают справочник).
- Тесты: `cd engine && NXLD_STRICT_CATALOG=1 python3 -m pytest -q tests`. На каждое исправление — тест, который без правки падает.
- Ошибки, найденные вне задачи, не чини: заведи задачу в GitHub (imageprom/NXLogDetective) с меткой `bug`. Не получается — опиши в отчёте отдельным пунктом.
- В конце — короткий отчёт таблицей (задача / коммит / что / как проверено) и отдельным списком решения вне задания.

## Структура отчёта утверждена
- Не переименовывай и не переделывай существующие листы, блоки, колонки.
- Не добавляй новые листы, блоки, таблицы или строки на существующие листы (сводки Обзоров, «Активность» и т. п.), если этого нет в задаче явно. Если без этого нельзя — сделай вывод выключенным и опиши в отчёте, где и что появилось бы.
- В отчёте перечисли все места (файл / лист / блок), где изменился вид отчёта.
- Невыбранный блок — нет его листов нигде.

## Термины (см. также задачи)
- Обращающийся описывается тремя признаками: категория (Люди · Роботы · Боты · Утилиты · Свои · Системы мониторинга), тип (что делает: парсер, скрапер, сканер, проверка сервиса, хотлинк…), сеть (дата-центр, домашний интернет, мобильный оператор).
- Не использовать: «программа» (робот — тоже программа), «скрапер с хостинга», «хостинг/облако» как подпись сети (→ «дата-центр»), «чужой сайт» (→ «внешние сайты»), «файлы без страниц» (→ «только файлы»).
- Числа в текстах: десятичная запятая, тысячи пробелом, число согласовано со словом.

## Данные
- Репозиторий публичный: никаких имён клиентов, их сайтов, IP посетителей, логов — ни в коде, ни в тестах, ни в коммитах, ни в задачах. В тестах — `example.com` и вымышленные данные.

## Справочники
- Новые ключи в JSON — латиницей. Тексты для отчёта — обычными строками в папке языка `data/locale/<язык>/`.
- Состав, порядок, вкладки и заголовки листов — в каталоге `data/locale/ru/report_structure.json` (после задачи #8). Лист вне каталога или не `approved` в отчёт не выводится.
